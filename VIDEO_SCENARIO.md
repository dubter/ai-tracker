```json
      "matcher": "Edit",
      "hooks": [{
        "type": "command",
        "command": "npx tsc --noEmit 2>&1 | head -5"
      }]
    }],
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{
        "type": "command",
        "command": "echo '[Hook] Bash команда: проверь что не удаляешь важное'"
      }]
    }]
  }
}
```

> "PostToolUse — срабатывает после каждого редактирования файла. Сразу гоним TypeScript.

>
> Есть ещё `block: true` — это уже жёсткая блокировка.
> Например: если Claude пытается выполнить rm -rf — команда вообще не выполняется."
